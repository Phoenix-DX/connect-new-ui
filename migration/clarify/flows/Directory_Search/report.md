## 1. Summary

- Counts by verdict: match 129 · partial 5 · missing 5 · differs 2 · mock-only 2 · n/a 3 · unclear 0 (same as `checklist.json`).
- **F1** (major): after a search, React always shows the caption "Showing results for". TST shows it only while
  the typed term differs from the last search.
- **F2** (major): before the first search, a category change does not refresh the recent results in React. TST
  refreshes them.
- **F3** (major): React shows no loading rows while a search runs. TST adds three placeholder rows to each section
  in scope (BR-UBTCON-880).
- **F4** (minor): the default of `In_SearchTargetId` is an empty text in React and `Global` on TST.
- **F5** (minor): the recent gallery does not give member avatars the square width of TST.
- Status: in React a user can search by name, place or phone number and filter by category and country. The user
  can open a result and manage the recent searches. The result caption, the loading rows and the recent list after
  a category change differ from TST. No finding blocks the flow.

# Known bugs of the original app

The React app reproduces the original app 1:1, bugs included (user, 2026-10-14). This file lists each bug that the
migration found, with its evidence. A later ADR can fix a bug. A fix changes the behaviour that users know, and parity
for that state then needs an exemption.

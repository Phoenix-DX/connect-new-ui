## Decisions of the group

Source: `migration/refactor/auto-decisions-2026-10-22.md` and `migration/refactor/log.md`.

- W27 (MilestoneDetail): accept the reload on back navigation of the old port. The 2 former crash paths of the old page (optional input missing, visit from a notification) now reload. OutSystems keeps the state. The open follow-up is F24, decided with F22.
- W28 (beforePaint): 10 old blocks run OnReady before paint, but `useFlowState` ran it after paint. Step P6-F17 added the opt-in `beforePaint` option. Pages whose old block ran OnReady before paint set it.

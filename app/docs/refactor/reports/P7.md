### Debt created by W32

`src/shared/` is gone, but its imports did not disappear. The dependency-cruiser run on the P7-6 tree shows 222 violations (warnings until P9-1). The new ones by rule:

| Rule | Count now | Change | Owner |
| ---- | --------: | ------ | ----- |
| 4 (`components/**` imports `api/`, `platform/` ...) | 36 | +1 (OSLink) | F36 |
| 5 (`components/ui/` imports) | 13 | -110 (a reclassification, see below) | F36 (OSLink, 1) |
| 6 (`lib/` imports only `lib/`) | 55 | +55 (ceiling) | F35 |
| 8 (`platform/` imports `components/`) | 20 | +1 (`UserInfoCache` imports `OSBlock`) | F37 |
| 9 (only `platform/`, `api/`, `app/` import `legacy/os/`) | 98 | +4 (base 94) | F37 |

- **Rule 6 ceiling 55 (F35).** The 8 module client-action files moved to `lib/<module>/actions.ts`. They mix pure helpers with `api/`, `platform/` and `legacy/os/` code, so `lib/` imports non-`lib/` code in 55 places (48 in the actions files, 6 type re-exports of api types in 4 `structures.ts` files, and `lib/ubtConnect/unsupportedVersion.ts`, which imports `@/mocks/scenarioParams` and `@/platform/config`). A later step may only lower this number. Rule 6 becomes an error at P9-1, so F35 (split the module client actions by data owner) must run before it.
- **OSLink (F36).** `components/ui/os/OSLink.tsx` imports `platform/navigation` (rule 4 +1, rule 5 +1). It should take its navigation by a prop or an app-level context.
- **CacheControl blocks (F37).** `legacy/os/cache/` now imports `api/client/cache` and `api/` domains, and `platform/session/UserInfoCache` imports `OSBlock`. The later step replaces the CacheControl blocks with the P0-5 api hooks and keeps only the `OSBlock` placeholders. Rule 9 +4 are `containers/FilterSheet`, `pages/TermsAndPoliciesMenu` and two type imports in `components/`.
- **Rule 5 drop (F38).** The fall from 122 to 13 is mostly a reclassification, not removed debt. `components/ui` imported files of `shared/`; those files now sit in `components/ui/` or `lib/`, where rule 5 allows the imports. The code has the same imports. The real debt is F35 to F37.
